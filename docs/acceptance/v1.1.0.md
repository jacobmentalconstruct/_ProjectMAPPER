## Boundaries and limitations

The adapters are local process interfaces, not operating-system sandboxes. An agent
with desktop-control access could click an approval popup; this is documented and not
claimed as resistant to screen-control software. MCP is stdio-only. Sessions and history
are per process and in memory. The Python 3.13 environment cannot run the SDK 2.x wire
test without replacing the installed MCP 1.x required by FastMCP, so that one test is
verified on Python 3.10 and 3.14 instead. macOS and Linux are not tested.
